# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-01

Первый публичный релиз.

### Чтение
- Служебный документ и `$metadata` (CSDL XML 4.0 и CSDL JSON) с именами `standard.odata`.
- Справочники, документы, табличные части, планы видов характеристик, счетов и видов расчёта, планы обмена,
  бизнес-процессы, задачи, константы, журналы документов, регистры всех видов.
- `$filter` с функциями, `any`/`all`, `in` и путями через ссылки; синтаксис v3 (`substringof`, `datetime'…'`, `guid'…'`).
- `$select`, `$expand` ссылок и табличных частей (до трёх уровней), `$orderby`, `$top`, `$skip`, `$count`.
- Постраничная выдача по ключу (`@odata.nextLink`, `Prefer: odata.maxpagesize`) или одним ответом.
- Виртуальные таблицы регистров: `SliceLast`, `SliceFirst`, `Balance`, `Turnovers`, `BalanceAndTurnovers`,
  `ExtDimensions`, `RecordsWithExtDimensions`, параметр `Periodicity`.
- Агрегация `$apply`: `filter`, `groupby`, `aggregate`, `compute`, `topcount`, `bottomcount`, цепочки шагов.

### Запись
- `POST`, `PATCH`, `PUT`, `MERGE`, `DELETE` через объектную модель с бизнес-логикой конфигурации.
- Проведение и отмена проведения (`Post`, `Unpost`), наборы движений регистров, константы, регистры сведений.
- ETag, `If-Match` и `If-None-Match`, повторяемые запросы (`Repeatability-Request-ID`, `Idempotency-Key`).
- `$batch` в форматах `multipart/mixed` и JSON; набор изменений выполняется одной транзакцией.

### Доступ и эксплуатация
- Роли расширения, профили доступа (объекты, операции, поля, отборы строк, лимиты, частота).
- Токены доступа: срок действия, отзыв, ограничение по IP, отдельная публикация `odatat`.
- Базовые лимиты запроса, CORS, журнал запросов, регламентная очистка.
- Форма «Настройки OData4».

### Производительность
- Ленивая модель, кэш `$metadata` между сеансами.
- Внешняя компонента на Rust для Windows и Linux (x86, x64): разбор параметров, выдача JSON, разбор тел,
  вывод `$metadata`. При её недоступности работает код на языке 1С.
