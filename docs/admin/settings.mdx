Все настройки сервиса собраны в одной форме: раздел **OData4** → **Настройки OData4**. Открыть её может пользователь
с ролью `OData4_Администратор`.

<Frame caption="Раздел «OData4» → «Настройки OData4»">
  <img src="/images/admin/app-section-odata4.png" alt="Раздел «OData4» → «Настройки OData4»" />
</Frame>

Настройки хранятся в информационной базе (регистр сведений `OData4_Настройки`, одна запись) и действуют
**со следующего запроса**: перезапускать веб-сервер или завершать сеансы не нужно.

<Info>
  Любой вариант поведения в форме — переключатель с безопасным значением по умолчанию. Рядом с каждым флажком
  написано, что нужно, чтобы включить другой вариант, и чем он рискован.
</Info>

Флажки с пометкой **[Экспериментально]** включают новые возможности, которые проверены, но по умолчанию выключены:

- разбор параметров компонентой;
- сверка движков;
- токены продолжения.

## Режим дат

| Режим | Как выдаются даты |
|---|---|
| **Строгий** (по умолчанию) | `Дата` → `Edm.Date`, `Время` → `Edm.TimeOfDay`, `Дата и время` → `Edm.DateTimeOffset` со смещением часового пояса базы; пустая дата → `null` |
| **Совместимый** | всё — `Edm.DateTimeOffset` с `Z`, как в `standard.odata`; пустая дата → `0001-01-01T00:00:00Z` |

«Совместимый» режим нужен клиентам, которые написаны под `standard.odata` и ждут даты в его виде. При записи в этом
режиме явное смещение `±чч:мм` переводится в местное время базы, а `Z` — нет: чтение тоже выдаёт местное время с `Z`.

## Предупреждение при запуске

Если в настройках есть опасные значения, при входе в 1С расширение показывает окно с их списком. Его видит тот, у
кого есть право «Администрирование» или роль `OData4_Администратор`. Опасные значения — например:

- разрешён вход по Basic служебным учёткам;
- выбран привилегированный режим;
- задан токен с ограничением по IP, но без доверенного заголовка адреса.

Окно немодальное и не мешает работе.
