У всех документов в `$metadata` объявлены связанные действия `Post` и `Unpost` с параметром `PostingModeOperational`. У `standard.odata` они описаны как `FunctionImport`.

## Адрес

Действие вызывается методом `POST` по адресу документа. Принимаются все формы:

```http
POST /base/hs/odata/v4/Document_РеализацияТоваровУслуг(guid'…')/Post
POST /base/hs/odata/v4/Document_РеализацияТоваровУслуг(guid'…')/Post()
POST /base/hs/odata/v4/Document_РеализацияТоваровУслуг(guid'…')/Post(PostingModeOperational=true)
POST /base/hs/odata/v4/Document_РеализацияТоваровУслуг(guid'…')/StandardODATA.Post
```

Параметр можно передать и в теле JSON:

```http
POST /base/hs/odata/v4/Document_РеализацияТоваровУслуг(guid'…')/Post
Content-Type: application/json

{ "PostingModeOperational": false }
```

`Unpost` вызывается так же и отменяет проведение.

| Результат | Ответ |
|---|---|
| Успех | `204` и `ETag` с новой версией документа |
| `GET` или другой метод на адрес действия | `405`, `Allow: POST` |
| Документ непроводимый | `400` |
| Ошибка проведения (`Отказ`, сообщения пользователю) | `400`, сообщения в `error.details` |
| Нет права «Проведение» / «Отмена проведения» в профиле или в 1С | `403` |

## Режим проведения

`PostingModeOperational=true` проводит оперативно, `false` — неоперативно. Режим для вызова без параметра выбирается на вкладке «Запись» в поле «Режим Post без параметра»:

- **Неоперативный** — по умолчанию;
- **Оперативный для документа сегодняшней даты** — документ с сегодняшней датой проводится оперативно, если вид документа это допускает.

## Проведение и изменение

- Проведённый документ после `PATCH` или `PUT` перепроводится, как при «Записать» в форме 1С. Для изменения проведённого документа нужно ещё право «Проведение».
- Пометка удаления проведённого документа снимает проведение.
- Проведение идёт в той же транзакции, что и запись. Ошибка откатывает всё.

<Tip>
Создать документ и сразу провести его одной транзакцией можно в наборе изменений `$batch`: `POST Document_X`, затем `POST $1/Post`. Пример — на странице [$batch](/write/batch).
</Tip>

Движения документа пишутся и в регистры вне состава публикации. Права на них дают роли конфигурации.

## Отличия от standard.odata

- Действие отвечает `204`, у `standard.odata` — `200` с пустым телом.
- `GET …/Post()` даёт `405`, а `standard.odata` проводит документ.
- Форма `…/StandardODATA.Post` и параметр в теле принимаются.
- Непроводимый документ и ошибки проведения дают `400`, а не `500`.

Подробнее — на странице [Отличия от standard.odata](/reference/differences).
