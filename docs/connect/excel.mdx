Excel подключается так же, как Power BI: через Power Query и источник «Канал OData».

## Токен в адресе (рекомендуется)

<Steps>
  <Step title="Возьмите адрес с токеном">
    Форма «Настройки OData4» → вкладка **«Токены»** → **«Выпустить»**. Готовый адрес вида
    `https://server/base-svc/hs/odatat/t/<токен>/v4/` показан при выпуске и на вкладке **«Адреса»**.
  </Step>
  <Step title="Подключите канал">
    **Данные → Получить данные → Из других источников → Из канала OData**, вставьте адрес.
  </Step>
  <Step title="Вход «Анонимный»">
    Токен уже в пути адреса.
  </Step>
  <Step title="Загрузите таблицы">
    В навигаторе выберите наборы и нажмите **«Загрузить»** или **«Преобразовать данные»**, чтобы выбрать колонки
    и отборы до загрузки.
  </Step>
</Steps>

Чтобы не держать токен в адресе, передайте его заголовком: **Данные → Получить данные → Из других источников →
Пустой запрос → Расширенный редактор**:

```powerquery
let
    Source = OData.Feed(
        "https://server/base-svc/hs/odatat/v4/",
        null,
        [Headers = [#"X-OData4-Token" = "o4_…"]]
    )
in
    Source
```

## Basic

Адрес основного сервиса `https://server/base/hs/odata/v4/`, вход **«Обычная»**, имя и пароль пользователя 1С с
ролью `OData4_Пользователь`.

## Советы

- Выбирайте только нужные колонки и отбирайте строки в Power Query: шаги «Удалить другие столбцы» и фильтры
  до первого сложного преобразования уходят на сервер как `$select` и `$filter`.
- Для сводных таблиц по регистрам берите виртуальные таблицы — `Balance()`, `Turnovers()` — или `$apply`:
  итоги считаются в базе, а в Excel попадают готовые строки. См. [Регистры](/read/registers).
- Обновление книги повторяет запросы к сервису. Если токен истёк или отозван, Excel покажет ошибку `401` с
  причиной — выпустите новый токен.
