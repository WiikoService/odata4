## Платформа и база

| | Требование |
|---|---|
| Платформа | 1С:Предприятие 8.3.11 и новее. Режим совместимости расширения — 8.3.11 |
| Конфигурация | любая, с БСП и без. Расширение берёт всё из метаданных конфигурации и не меняет её объекты |
| Вариант базы | файловая и клиент-серверная (MS SQL, PostgreSQL и другие СУБД, которые поддерживает платформа) |
| Веб-сервер | Apache 2.2/2.4 или IIS с модулем расширения веб-сервера 1С |

<Note>
  В файловой базе регламентные задания выполняет клиентский сеанс. Регламентная очистка журнала и
  служебных данных OData4 работает, только пока открыт сеанс, обрабатывающий задания. В клиент-серверной
  базе задания выполняет сервер. Подробнее — [Журнал запросов](/admin/journal).
</Note>

## Внешняя компонента

Ускорение выдачи JSON, разбора тел запросов и вывода `$metadata` даёт внешняя компонента на Rust. Она
уже собрана и лежит в расширении для:

- Windows x86 и x64;
- Linux x86 и x64 (glibc 2.17 и новее).

Компонента подключается на стороне веб-сервера, где выполняются сеансы HTTP-сервисов. Если она недоступна
(другая ОС, безопасный режим расширения, сбой), сервис отвечает теми же ответами на языке 1С, только медленнее
на больших выборках. Подробнее — [Внешняя компонента](/admin/native).

## Права для установки

- доступ к конфигуратору с правом «Администрирование» — чтобы загрузить расширение и обновить базу;
- право публиковать базу на веб-сервере (на Windows — запуск от администратора);
- пользователь с правом «Администрирование» в режиме 1С:Предприятие — чтобы назначить роли и сохранить
  снимок состава стандартного интерфейса.

## Клиенты

Любой клиент OData v4 или HTTP: Power BI Desktop и Service, Excel (Power Query), Postman, curl, библиотеки
OData для .NET, Python, JavaScript. Подробнее — [Подключение](/connect/power-bi).
