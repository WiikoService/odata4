# Безопасность

## Как сообщить об уязвимости

Не публикуйте уязвимость в открытых Issues. Сообщите о ней закрыто: вкладка
**Security → Report a vulnerability** этого репозитория (GitHub Private Vulnerability Reporting).

Укажите версию OData4 и платформы, запрос, который воспроизводит проблему, и чем она грозит.
Мы подтвердим получение в течение трёх рабочих дней и сообщим срок исправления.

## Поддерживаемые версии

Исправления безопасности выходят для последнего релиза. Обновляйте расширение до последней версии.

## Рекомендации по эксплуатации

- Публикуйте сервис наружу только через HTTPS.
- Для Power BI, Excel и внешних систем используйте токены с ограниченным профилем, а не пароли пользователей 1С.
- Для публикации токенов публикуйте только сервис `odatat`.
- Ограничивайте токены по IP за доверенным прокси.

Подробно — в разделе [«Доступ и безопасность»](https://docs.wiiko.by/odata4/security/overview) документации.
